Popup links

Point to this link with a mouse: home page. A window opens with that page. Links in the window open more windows. Pin a window to keep it, and drag it by its title bar. Escape closes the windows that are not pinned.

In the content, a link gets a bare data-pop attribute. The build wraps it in <pop-link> and points it to the page body under /frag/.

Checklist

Tick an item. It moves to the bottom of the list. This browser keeps the ticks.

List filter

Each word that you type must be in an item, or the item is hidden. Without JavaScript, the filter box does not show.

Steps and callouts

A numbered list with the class steps. An item with the class note, caution or warning is a callout.

  1. Do the first step.

  2. note A note gives more information.

  3. Do the second step.

  4. caution A caution tells you how to prevent damage.

  5. warning A warning tells you how to prevent injury.
